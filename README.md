## 🚀 Features

- **Basic Operations** — Addition, Subtraction, Multiplication, Division
- **Percent** — Instantly convert to percentage
- **Backspace** — Delete last entered character
- **AC (All Clear)** — Reset the calculator
- **Expression Display** — Shows full equation before result
- **Keyboard Support** — Use number keys, operators, Enter, Backspace, Escape
- **Error Handling** — Shows error for invalid input or division by zero
- **Responsive Design** — Works on all screen sizes
